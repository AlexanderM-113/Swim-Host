A downloadable swimming software app. Hosts on the computer – downloaded via a .exe file. 
MUST HAVES 
Main Components
-	Swim Meet Manager Interface
-	Workout Manager Interface
-	Team Manager
-	Scoreboard Interface
Swim Meet Manager Interface Components
-	Meet Set-up module with the following questions (Name, Date, Facility, Address, City/State, Country, Postal Code. Start/End & Age Up Dates, entry deadlines. ID format for the following Usa Swimming USAS, SNZ, SSSA, AUS, BS, BCSSA, USMS, Other, Host LSC, Altitude. Class (Age Group, Senior, High School, College, YMCA, Masters, PARA)) Meet Type: Standard, and divisions by event, team, entry, flighted or time standards. Meet Style: standard, 2 team dual, 3+ team dual meet, Course: LC Meters, SC yards, SC Meters. DQ Codes: FINA or USAS. Time Adjustment Method in FINA rules or USA Swimming Rules. Also, entry fees will be determined here. Import meet logo.
-	Seeding – Preferences menu – Course order, non-conforming course, lane assignments, lanes for pools 6 lanes, 8 lanes, 10 lanes. Circle seed or custom seed. Shows number of heats, entries, ect. Scratch seeding – automatically after a race the first 16places + 2 alternates make it to finals, as people scratch they are removed from that list making it to finals and the next person moves up. After the scratch deadline there will be 16 swimmers and 2 alternates available to seed. Seeding will go into 2 groups the A-final and the B-final. Those who scratched will not appear in the finals section of a report but they will show their prelim time. And in results only the prelim time/place will show for those who scratched in time.
-	Events Menu – event number, gender (M, F, Mixed) Age Group, Distance, Stroke, Options: Standard Seeding, Heat order slow-fast or fast-slow. Event Type: standard, time trial, swim-off, open water.  Sessions and ability to rearrange events into certain sessions on certain days and set prelim/final/timed final sessions. Time standards for meet.
-	Athlete menu – Name (First/Last), gender, age, team/school, ID number, b-day. Ability to delete, edit events and scratch. 
-	Relay Menu – shows relay events, we can see entries and relay orders, ability to change relay orders, lane, entry time. And ability to add relays
-	School/Team Menu – name, abbreviation, lsc, short name, coach name, address. Ability to edit teams info
-	Run menu – event list shows events for the session with heats, dqs, ns, dnfs. Shows cumulative splits, team scores, and auto scores races based off scoring prefrences. Ability to automatically publish live results to a .html website for the meet – see Web menu, ability to create swim-off events and time trial events, ability to combine event results, this menu automatically connects and imports data  from a timing system via the interface module. Ability to enter results by lane and enter alternate times based off USAS/FINA rules for backup timing.
-	Interface Module – Timing console selecton – Colorado time systems, omega time systems, Daktroniks, ALGE SWIM, BestBET, Incomar, Kyrotech Tec-Timer, Wylas Timing, Seiko Time, Genertic Network File Sharing, custom Arduino timing connection. Scoreboard connection to Colorado timing, Daktronics, Omega, Generic, or Network File sharing all scoreboard via Serial port/ USB to serial or UDP ethernet. Open water interface for timing systems such as time tech, time machine, chronomix, nielsen Kellerman, omega, ultrak, finishlynx, Daktronics. 
-	Scoring Preferences – order of finish scores (ex. 1st place = 20pts.) custom scores, FINA rules and USAS, NFHS scoring rules.
-	Web Menu – Creates a website in html to automatically post meet results, split times ect. On this website there is a scratchpad for swimmers to scratch from finals. Scratching works like this – a swimmer who doesn’t want to swim finals must fill out a form with the following info –their FULL name,b-day,  event they are scratching from, and sign it, then submit the form and the system automatically scratches the swimmer from the race. There is a scratch time window, the meet manager must start the time window when they want to – that starts a 30min timer to scratch. When 30min is up anyone who has not scratched makes finals according to the scratch/seeding prefrences. When 30min is up the system will automatically take the new list of swimmers and auto seed them for the finals session. Web menu also generates a qr code for people to visit the website.
-	Import/Export & Reports – Files will be imported/ exported into and out of the system in a .hy3/.cl2 swimming standard file or swimming SDIF type file. 
-	Reports – Reports will be exported and printable in a pdf file. Reports include Admin: DQ lists, Award Counts, PDF forms, Events reports: will include everything from the event menu, School Reports will include all the data from the school menu, Athlete reports will include everything from the athlete menu. Records and time standards will be able to be generated from here. Crucial Reports are as follows: Entry Lists by Team, Split Sheets for coaches, Psych Sheets for families, Heat Sheet for athletes (shows what event/heat/lane they are in), Meet Check-In/Postitve Check in for athletes, Lane/Timer sheets for backup stopwatch timing, results & scores report with all results across all sessions.  And a meet flyer report with the logo of the meet, all the data about the meet including head official and admin, a liability disclaimer, the standard USAS rules for sanctioned meets, and the order of events with warm-up/start times and postitive check in times. And meet entry fees/ where to send them to.
-	Meet backup database
Any data that I left out look up.

Workout Manager Interface Components
-Workout designing software, with start/end times, distance, type of stroke, and the workout that the coach types in. 
- sample workouts can be loaded in.
Team Manager Interface components
-	Athlete management – with athlete data, ID number, name , DOB, Phone number/Email, parent contact info, notes, health issues
-	Team entries, events can be imported into the system via .hy3/cl2 file and entires can be done for the team then exported in the same file type
-	Billing management for the team – including meet fees, group monthly prices, ect. 
-	Reports in pdf style such as meet entry report, invoices, bills, official memos, ect.
-	This system also generates a  website for each familiy with their data, workouts they participated in, their billing info – including credit card/ ACH. The ability for them to enter themselves in team events ect. And a qr code so they can access it
Scoreboard Interface
-	Scoreboard connects to makor scoreboard types
-	Can display live meet scoreboard with what is going on in the current race
-	Can diplay live workout
-	Can display videos, images, or custom designs
-	Can display live pace clock for workouts

Style for the entire app is swimming themed but individual users can change it how they want.
